## Play

- Open https://kettuvellam.com in a web browser and wait past the Launching onto the backwaters loader into the GameLoader client
- Select a race course when offered: Punnamada Lake, Kuttanad canals, or the Vembanad monsoon-storm course
- Race a chundan vallam snake boat against rival crews to the finish line
- Check the live leaderboard for race results
